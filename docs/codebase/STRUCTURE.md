# Find My Mouse — Codebase Structure

## Directory Layout

```
.
├── src/                          # TypeScript source (edit here)
│   ├── extension.ts              # Lifecycle, wiring, pointer/gesture handlers
│   ├── prefs.ts                  # Adwaita/GTK4 preferences UI
│   ├── settings.ts               # GSettings wrapper, cache, color normalization
│   ├── activationController.ts   # Show-only activation + idle timeout
│   ├── gestureDetector.ts        # Pure "wave then stop" state machine (no imports)
│   ├── gestureFeedback.ts        # Pointer-local progress ring + optional sound
│   ├── spotlight.ts              # 4 dim actors + small Cairo mask, Clutter zoom
│   ├── spotlightLayout.ts        # Pure mask/dim rectangle layout math (no imports)
│   ├── mouseTracking.ts          # pointerWatcher adapter, guards, settle clock
│   ├── gamemodeClient.ts         # GameMode D-Bus client
│   ├── practiceService.ts        # Shell-side practice D-Bus service + 10 s watchdog
│   ├── practiceClient.ts         # Preferences-side practice D-Bus proxy
│   ├── utils.ts                  # Logging and color parsing
│   └── codemap.md                # Source directory atlas
├── schemas/
│   ├── org.gnome.shell.extensions.find-my-mouse.gschema.xml  # 20 keys
│   ├── gschemas.compiled        # Generated binary schema
│   └── codemap.md                # Schema directory atlas
├── test/
│   ├── gestureDetector.test.mjs  # node:test gesture scenarios
│   └── spotlightLayout.test.mjs  # node:test mask/dim tiling scenarios
├── dist/                         # Compiled JS (gitignored, generated by npm run build)
├── docs/codebase/                # These analysis documents
├── metadata.json                 # UUID, version 1.0.0, GNOME 46–50
├── AGENTS.md
└── codemap.md                    # Repository atlas
```

Development is in `src/*.ts`; the Shell loads the compiled `dist/*.js`. The activation shortcut is registered in `extension.ts` with `Main.wm.addKeybinding()`.

## Entry Points

| File | Role |
|---|---|
| `src/extension.ts` | Extension lifecycle; creates and connects all subsystems. |
| `src/prefs.ts` | Adwaita/GTK4 preferences dialog. |
| `metadata.json` | Extension UUID, name, version, shell compatibility. |

## Key Files

### `src/extension.ts`
- `FindMyMouseExtension` (extends `Extension`).
- Managers: `SettingsManager`, `SpotlightManager`, `MouseTracker`, `GameModeClient`, `ActivationController`, `GestureFeedback`, `PracticeService`.
- Registers `find-my-mouse-activation` with `Main.wm.addKeybinding()`; shortcut is always available.
- Handlers: `_handleMouseMovement()`, `_handleGestureEvent()`, always-visible/GameMode/settings signals.

### `src/mouseTracking.ts` and `src/gestureDetector.ts`
- `MouseTracker` adapts pointerWatcher samples to `GestureSample {dx, dy, tMs}`, applies guards, owns the authoritative last position, and runs a 16 ms settle clock only during an attempt.
- `GestureDetector` is import-free: state machine `idle → tracking → ready → cooldown`, events `none|armed|progress|ready|activated|aborted`, thresholds injected via `GestureConfig`.

### `src/activationController.ts`
- `activate(source)` is show-only; repeat activation refreshes the idle timeout.
- Checks GameMode suppression, schedules/clears the idle timeout, requests the optional confirmation sound.

### `src/gestureFeedback.ts`
- Small `St.DrawingArea` progress ring shown only during an attempt; arcs per reversal, bright "stop now" state, immediate teardown.
- Best-effort `canberra-gtk-play` invocation for `gesture-sound`.

### `src/spotlight.ts`
- `SpotlightManager`: `show()`, `hide()`, `isVisible`, geometry, Cairo mask rendering, `Clutter.Timeline` zoom. Uses the import-free `spotlightLayout.ts` to place the mask and four dim actors; rendering/animation only — no idle timer.

### `src/settings.ts`
- `SettingsManager`: caches and normalizes the schema values used by the shell; the keybinding API handles `find-my-mouse-activation` and `ActivationController` reads `show-on-all-monitors` when showing the spotlight. The detector uses only the `gesture-*` values.

### `src/prefs.ts`
- Pages: General, Appearance, Timing, Mouse Gesture, About. Presets, fine-tuning expander, live "Try the Gesture" practice with text-only fallback, reset-to-defaults controls.

### `src/practiceService.ts` and `src/practiceClient.ts`
- Shell-side session over the session bus: `Start()`/`Cancel()`, `Progress`/`Result` signals, 10 s watchdog; practice never calls the real activation path.
- Prefs-side `Gio.DBusProxy` with retry, signal dispatch and graceful behavior across extension reloads.

### `src/gamemodeClient.ts` and `src/utils.ts`
- GameMode D-Bus proxy with retry; logging (`debugLog`, levels) and color parsing.

### `test/gestureDetector.test.mjs` and `test/spotlightLayout.test.mjs`
- Detector tests use `node:test` with synthesized pointer streams and injected timestamps: a normal 900 ms window/180 ms settle gesture activates, while slow, small pointer steps (three ~30 px steps 1500 ms apart) do not.
- Layout tests check mask/dim tiling, negative monitor origins, edge clipping, zoom larger than the monitor and fractional radius with zero ring width.
